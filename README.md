# Expenses Tracker

Expenses Tracker is a personal project for tracking spending. It allows me to review where my money goes and where I can improve my spending.

## Features

- Track expenses with an amount, date, and description
- Organize spending by category
- Review recorded expenses to understand spending patterns

## Getting Started

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1  # powershell command
```

```bash
uv pip install -e .
```

Accessing DB UI

```bash
duckdb -ui
```
